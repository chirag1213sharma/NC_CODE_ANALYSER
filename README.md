# NC Code Analyser with AI

An intelligent automated system for analyzing NC (Numerical Control) code differences and assisting in regression detection for CNC manufacturing workflows.

## 🎯 Overview

This system integrates AI (Gemini 2.5 Pro) with CNC manufacturing workflows to automate the analysis and validation of NC code generated by CAM software like CAMWorks.

### Key Features

- **NC File Parsing**: Structured extraction of operations, tools, coordinates, feeds, speeds
- **Intelligent Comparison**: Operation-wise difference detection between baseline and new NC files
- **AI Classification**: Automatic categorization of changes as Regression/Progression/Neutral
- **Feedback Learning**: Vector database-powered continuous improvement from QA corrections
- **Dashboard & Reports**: Visual diff display and exportable reports for stakeholders

## 🚀 Quick Start

### Prerequisites

- Python 3.10+
- PostgreSQL 14+
- Node.js 18+ (for frontend)

### Installation

1. **Clone and setup environment**

```bash
cd NC_CODE_ANALYSER
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

2. **Configure environment**

```bash
copy .env.example .env
# Edit .env with your Gemini API key and database credentials
```

3. **Initialize database**

```bash
alembic upgrade head
```

4. **Run the application**

```bash
python -m uvicorn src.main:app --reload
```

5. **Access the dashboard**
   Open in your browser - http://localhost:8000/

## 📊 NC Code Classification

The AI classifies changes into three categories:

| Category        | Description                              | Example                                 |
| --------------- | ---------------------------------------- | --------------------------------------- |
| **Regression**  | Undesired change affecting functionality | Incorrect tool path, missing operations |
| **Progression** | Expected improvement                     | Optimized feeds, better toolpath        |
| **Neutral**     | No functional impact                     | Comment changes, whitespace             |

## 🔄 Feedback Loop

The system captures QA corrections to a JSON file (`feedback.json` in the
repo base directory) in a fine-tune ready chat format:

1. AI makes initial classification
2. QA engineer reviews and corrects if needed
3. Correction is appended to `feedback.json` as a `{system, user, assistant}`
   training sample (assistant message matches the model's JSON output schema)
4. The accumulated file can be used directly to fine-tune the local LLM
   (e.g. Mistral via LoRA/QLoRA)

## 📈 API Endpoints

| Endpoint             | Method | Description                  |
| -------------------- | ------ | ---------------------------- |
| `/api/files/upload`  | POST   | Upload NC files              |
| `/api/compare`       | POST   | Compare baseline vs new file |
| `/api/analysis/{id}` | GET    | Get analysis results         |
| `/api/feedback`      | POST   | Submit QA feedback           |
| `/api/reports/{id}`  | GET    | Generate report              |
